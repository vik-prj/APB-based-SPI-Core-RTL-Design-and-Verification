# APB-based-SPI-Core-RTL-Design-and-Verification
Designed full-duplex SPI controller compliant with AMBA APB3 protocol using Verilog HDL. Built complete UVM environment including sequence, driver, monitor, agent, and scoreboard. Implemented SVA protocol assertions for APB and SPI transaction validation. Achieved 100% functional coverage closure using constrained-random testing and cross coverage.
